# Публичная оферта

Здесь текста больше нет, и это сделано намеренно.

Действующая редакция лежит в `web/src/content/legal/offer.md` — именно её отдаёт сайт по адресу
`/legal/offer`. Раньше документ существовал в двух копиях, они разошлись, и однажды
это кончилось бы публикацией устаревшей редакции. Для юридического документа
такая ошибка стоит дорого.

Правки вносятся только в файл по ссылке выше. Номер редакции и дату действия
задаёт `web/src/lib/legal.ts`: при изменении текста поднимайте версию, иначе
согласия пользователей будут ссылаться на редакцию, которой они не видели.
